# 검증 범위와 재현 방법

이 프로젝트는 암호 통신을 관찰하기 위한 교육용 구현입니다. 자동 테스트는 구현의 기대 동작을 확인하며 프로토콜의 공식 보안 증명을 제공하지 않습니다.

## 로컬 검증 기록

2026-11-18, Windows 11 x64 / Python 3.14.8 / cryptography 49.0.0 / pytest 9.2.0 환경에서 확인했습니다.

- 소스 전체 검증: 64개 통과, 종료 코드 0.
- Windows EXE 내장 검증: 63개 통과, 1개 건너뜀, 종료 코드 0. 소스 인터프리터로 frozen 경로를 가상화하는 검사만 건너뛰며 실제 EXE 작업자 실행은 별도로 확인했습니다.
- 작은 수·Group 14에서 독립 Alice/Bob 프로세스의 실제 TCP 통신과 메시지 왕복을 확인했습니다.
- 잘못된 키·변조·재전송·잘못된 입력·타임아웃의 기대 거부와 웹 API의 로컬 요청 제한을 확인했습니다.
- ZIP을 한글과 공백이 있는 새 경로에 풀고 PATH에 시스템 폴더만 남긴 상태에서 실행했습니다. 기존 Python 설치 경로에 의존하지 않는 배포 동작을 확인했습니다.
- 실행 창·브라우저 자동 열기, 중복 실행, 포트 충돌 회피, 정상 종료와 프로세스 정리를 확인했습니다.
- 390px 모바일과 1440px 데스크톱 레이아웃에서 가로 넘침과 연결 중 브라우저 콘솔 오류 없이 실험이 완료됐습니다.

검증한 운영체제는 위 Windows 환경입니다. GitHub Actions 파일은 포함하지만 원격 실행 결과는 실제 워크플로 실행 이후에 확인해야 합니다.

## 직접 재현하기

소스 저장소 루트에서 실행합니다.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
```

이미 개발 환경을 준비했다면 다음 명령도 같습니다.

```powershell
.\.venv\Scripts\python.exe scripts/run_tests.py
```

결과는 `tests/output.txt`, `tests/results.json`, `tests/results.xml`에 저장됩니다. 생성된 결과·실험 키·로그는 Git 추적 대상에서 제외합니다. 배포본에서는 **전체 검증 실행** 버튼으로 실제 내장 테스트를 실행할 수 있으며 결과는 `%LOCALAPPDATA%\CryptoDHLab\tests`에 남습니다.

## 검증의 한계

다른 Windows PC나 가상 머신에서의 호환성, 코드 서명, 외부 공개 서버 운영은 검증하지 않았습니다. Python 정수 연산의 상수 시간 동작이나 상용 키 교환 프로토콜과 같은 보안 보장을 주장하지 않습니다.
