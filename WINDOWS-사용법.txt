Crypto DH Lab · 눈으로 배우는 암호 통신 · Windows x64

1. ZIP 파일을 받았다면 폴더 전체를 먼저 압축 해제하세요.
2. CryptoDHLab.exe를 더블클릭하면 작은 실행 창과 기본 브라우저가 열립니다.
3. 처음에는 '작은 수 · 수학 학습'과 '정상 통신'을 선택하고 '실험 시작'을 누르세요.
4. 종료할 때는 작은 실행 창의 '종료' 버튼을 누르거나 창을 닫으세요.

Python 설치, 명령어 입력, 인터넷 연결 없이 실행합니다.
EXE와 _internal 폴더를 함께 보관하세요. EXE만 옮기면 실행되지 않습니다.
실행 파일을 다시 누르면 실행 중인 실습 화면을 다시 엽니다.
8765 포트가 사용 중이면 빈 로컬 포트를 자동 선택합니다.

실행 기록과 키는 사용자별 %LOCALAPPDATA%\CryptoDHLab에 저장합니다.
실행 창의 '기록 폴더 열기' 버튼으로 확인할 수 있습니다.
'전체 검증 실행'은 배포본에 포함된 실제 테스트를 실행합니다.
브라우저 탭만 닫으면 서버는 유지됩니다. 종료는 작은 실행 창에서 하세요.

추천 순서: 작은 수 계산 → 큰 수 키 교환 → 패킷 변조·인증 실패 비교.
앱의 '학습 가이드' 탭과 소스 저장소의 docs/LEARNING.md를 참고하세요.
교육용 로컬 실습입니다. 복호화 메시지가 로그에 남으므로 민감한 내용은 입력하지 마세요.
코드 서명이 없는 배포본으로 Windows에서 출처 확인 안내가 표시될 수 있습니다.
